# Obtenir les objets dans la bonne faction

Un contrôle de 58 identifiants du premier catalogue, marqués pour les deux factions, complété par une nouvelle main gauche du félin, a comparé la liaison au ramassage de chaque pièce, ses sources dans ForeverDB et la base du simulateur. Douze pièces dépendent d’un vendeur d’honneur dans la salle de leur faction. Sept autres viennent d’une quête de l’Alliance. EasyBIS filtre ces 19 identifiants tant que la base locale donne exclusivement la source vérifiée. Si une autre quête ou un autre vendeur apparaît dans les données, le générateur laisse de nouveau les deux factions visibles pour réexamen. Il ne fabrique aucun jumeau.
